# Расписание АмГУ

Файлы обновлений Android-приложения «Расписание АмГУ»
(расписание занятий, личный кабинет, QR-пропуск, заметки).

Исходный код здесь не публикуется.

## Установка / обновление

1. Откройте последний релиз ниже (раздел Releases).
2. Скачайте `AmursuSchedule-<версия>.apk`.
3. Установите поверх текущей версии — данные сохранятся.
4. При первом запуске разрешите установку из этого источника,
   когда система спросит.
